## ナビゲーション全体（深リンク対応）

URL 構造（ハッシュルーティング）:

| URL | 状態 |
|-----|------|
| `#/` | サマリ（既定スプリント） |
| `#/summary` | サマリ |
| `#/progress` | 進捗 |
| `#/gantt` | ガント |
| `#/issues` | 課題管理 |
| `#/reports` | レポート |
| `#/issues/ECOM-1234` | 課題管理タブ + ECOM-1234 のモーダル開いた状態 |
| `#/sprints/sprint-23/progress` | Sprint 23 を選択した進捗タブ |

Slack に貼られた URL を踏むと、該当チケットが既に開いた状態で表示される（UX #7）。

## キーボードショートカット表

| キー | 動作 |
|------|------|
| `/` | フィルタの検索ボックスにフォーカス |
| `Cmd+K` / `Ctrl+K` | グローバル検索パレット |
| `Esc` | モーダル / パレットを閉じる |
| `Cmd+S` / `Ctrl+S` | モーダル内で保存 |
| `g s` | サマリタブへ |
| `g p` | 進捗タブへ |
| `g g` | ガントタブへ |
| `g i` | 課題管理タブへ |
| `g r` | レポートタブへ |
| `n` | 新規課題作成 |
| `?` | キーボードショートカット一覧表示 |

Vim ライクな `g + キー` 移動は実装オプション（YAGNI なら省略可）。

## 受け入れチェックリスト（UX Agent → Frontend Agent）

実装時に以下が満たされていれば UX 合格:

- [ ] サマリタブを開いて 3 秒以内に「自分の今日のタスク」が見える
- [ ] 担当者テーブルに進行中件数と Review 滞留が表示されている
- [ ] フィルタ適用中はフィルタバーが青く強調されている
- [ ] `/` キーで検索ボックスにフォーカス移動
- [ ] `Cmd+K` でパレットが 50ms 以内に開く
- [ ] モーダルが開いたら最初の input にフォーカス
- [ ] `Esc` でモーダル / パレットが閉じる
- [ ] エピックヘッダーに進捗バー + ETA が表示されている
- [ ] ガント上部に「今日に移動」ボタンがある
- [ ] 編集モーダルの「詳細を表示」が折りたたまれている
- [ ] `#/issues/ECOM-1234` の URL で直接該当チケットを開ける
